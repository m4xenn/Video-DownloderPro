# Video Downloader Pro 1.3.0

## A redesigned desktop workspace

- New blue-and-navy interface, light and dark themes, and clearer download controls.
- Dedicated New, Queue, History, Guide, and Settings pages inside the main window.
- Stable window layout across pages, smoother navigation, and theme switching without flashing text.
- A larger multi-link entry area makes better use of tall displays. The app opens maximized.
- New application, installer, and Windows notification icon.

## Easier to learn and use

- Swipeable first-run welcome tour introduces the main features.
- Offline feature guide includes 70 actual interface screenshots localized for all 10 supported languages.
- Search and filter the live queue, with clearer empty states and recovery actions.
- History includes cover images and inline video/audio previews. Playback uses the saved local file; unsupported codecs can be opened in the system player.
- Settings remain open after saving, and navigation stays accessible with long lists.
- Queue-completion Windows notifications continue to work while the application is open.

## Compatibility

- Keeps the existing installer identity and preserves settings, history, drafts, and paused downloads during upgrades.
- Application updates and yt-dlp/FFmpeg component updates remain separate.
- Clip/cut downloading remains outside this release.
- Download availability depends on the source platform; browser preview support depends on the media codec.

Download **VideoDownloaderPro_Setup.exe** and run it to install or upgrade. **SHA256SUMS.txt** contains the installer checksum.
